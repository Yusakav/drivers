# BQ25710 全寄存器详解与功能说明

> 基于 TI BQ25710 数据手册 SLUSD20B（Rev. B, April 2023），SMBus 从地址 12h（7-bit 地址 0x09）。

---

## 一、整体概述

### 1.1 芯片定位

BQ25710 是 TI 推出的**同步 NVDC（窄电压直流）Buck-Boost 电池充电控制器**，面向笔记本、超极本、可拆卸平板、移动设备等 1s~4s 电池充电应用。NVDC 架构使系统可在电池完全耗尽或被移除时仍然运行，且不低于最小系统电压。

### 1.2 核心架构

- **功率拓扑**：同步 Buck-Boost 四开关转换器，支持 Buck / Buck-Boost / Boost 三模式无缝自动切换，无需主机干预
- **功率路径**：BATFET（P 沟道 MOSFET）将系统与电池分离，实现 NVDC 功率路径管理
- **控制接口**：SMBus 从设备（仅响应 Write-Word / Read-Word 协议，不发起通信）
- **内部 LDO**：REGN（6V 线性稳压器）为栅极驱动器和内部参考供电
- **封装**：32-Pin WQFN 4mm × 4mm

### 1.3 设备对比表关键差异

BQ25710 相比 BQ25700A 的增强项（数据手册第 5 页 Table 6-1）：

| 参数 | BQ25700A | BQ25710 |
|------|----------|---------|
| VAP（IMVP9） | 不支持 | **支持** |
| Pass Through Mode | 不支持 | **支持** |
| OTG 电压范围 | 4.48V~20.8V | **3.0V~20.8V** |
| OTG 电压分辨率 | 64mV | **8mV** |
| 充电电压分辨率 | 16mV | **8mV** |

### 1.4 SMBus 接口参数

| 参数 | 规格 |
|------|------|
| 从地址（7-bit） | `0x09` (0001001b) |
| 从地址（8-bit 写） | `0x12` (00010010b) |
| 从地址（8-bit 读） | `0x13` (00010011b) |
| 时钟频率 | 10 kHz ~ 100 kHz |
| 支持协议 | Write-Word / Read-Word（仅从设备） |
| ManufacturerID 寄存器 (0xFE) | 0x0040（固定） |
| DeviceID 寄存器 (0xFF) | 0x0089（SMBus 设备 ID） |
| SMBus 超时 | 25 ms（最小）~ 35 ms（最大） |
| SDA/SCL 输入低阈值 | 0.8V（最大） |
| SDA/SCL 输入高阈值 | 2.1V（最小） |
| 开漏输出饱和电压（SDA/CHRG_OK/CMPOUT） | 0.4V（5mA 灌电流时） |

## 二、按功能模块逐一详细说明

### 2.1 充电核心功能

#### 2.1.1 电池支持与充电参数

| 参数 | 规格 | 寄存器 |
|------|------|--------|
| 电池节数 | 1s ~ 4s（由 CELL_BATPRESZ 引脚偏置决定） | — |
| 输入电压范围 | 3.5V ~ 24V | — |
| 充电电压范围 | 1.024V ~ 19.200V | MaxChargeVoltage (0x15) |
| 充电电压分辨率 | **8mV**（12-bit DAC，bit[14:3]） | 0x15 |
| 充电电压精度 | ±0.5%（0°C~85°C，16.8V 时）；±1.1%~1.2%（4.2V 时） | — |
| 充电电流范围 | 0 ~ 8128mA（10mΩ 检流电阻） | ChargeCurrent (0x14) |
| 充电电流分辨率 | **64mA**（7-bit DAC，bit[12:6]） | 0x14 |
| 充电电流精度 | ±2%~±5%（2048mA~1024mA 典型值） | — |
| 拓扑转换 | Buck / Buck-Boost / Boost 自动无缝切换 | — |

#### 2.1.2 充电模式

- **预充电（Precharge，LDO 模式）**：电池电压 < 最小系统电压时，BATFET 工作在线性模式，将系统电压维持在 MinSystemVoltage() 设定值
  - 2s~4s：预充电电流钳位 384mA
  - 1s：电池电压 < 3V 时钳位 384mA；3V < 电池电压 < 最小系统电压时，快充电流钳位 2A
- **恒流（CC）快充**：电池电压 > 最小系统电压后，BATFET 全导通，按 ChargeCurrent 设定恒流充电
- **恒压（CV）**：电池电压达到 MaxChargeVoltage 设定值时，转为恒压充电
- **终止**：主机写 ChargeCurrent = 0 或 CHRG_INHIBIT = 1 停止充电

#### 2.1.3 软启动

充电使能后，充电电流以 64mA 步进、每步 8μs 的速率软启动。

---

### 2.2 NVDC 功率路径管理

BATFET（P 沟道 MOSFET）将系统节点（VSYS）与电池（BAT）分离：

| 模式 | BATFET 状态 | 系统电压 |
|------|------------|---------|
| 电池电压 < 最小系统电压 | LDO 线性模式 | 维持在 MinSystemVoltage() 设定值 |
| 电池电压 > 最小系统电压（充电中或补充模式） | 全导通 | VSYS = VBAT + VDS(BATFET) |
| 充电关闭、无补充电流 | 关闭（理想二极管模式） | VSYS = VBAT + 160mV |
| 适配器满载、负载 > 适配器能力 | 理想二极管（补充模式） | 电池自动补充系统功率 |

**BATDRV 驱动能力**：仅能驱动 Ciss < 5nF 的 P 沟道 MOSFET，推荐 1nF~3nF。

**无 BATFET 配置**（手册 §9.6.5.1）：VSYS 短接至 SRP，需特殊上电序列（先进入 Hi-Z，禁用 LDO，再退出 Hi-Z 时设低输入电流限制避免浪涌）。

---

### 2.3 输入源动态功率管理（DPM）

#### 2.3.1 IDPM（输入电流调节）

- 总输入电流限制 = **min(ILIM_HIZ 引脚设定, IIN_HOST 寄存器设定)**
- 默认 IIN_HOST = 3.25A (0x4100)
- ILIM_HIZ 引脚电压公式：V(ILIM_HIZ) = 1V + 40 × IDPM × RAC（RAC 为检流电阻）
- 当系统功耗增加时，自动降低充电电流以维持总输入电流不超过限制
- 可通过 REG0x31[7] = 0 禁用 ILIM_HIZ 引脚（仅用寄存器设定）

#### 2.3.2 VDPM（输入电压调节）

- 范围 3.2V ~ 19.52V，LSB 64mV
- 默认值 = VBUS 空载电压 − 1.28V（上电时自动测量）
- 输入电压低于设定值时降低充电电流，防止输入源电压崩溃

#### 2.3.3 两级适配器电流限制（Peak Power Mode / 峰值功率模式）

充分利用适配器短时过载能力，最小化 Turbo 模式下的电池放电：

- **ILIM1**（DC 额定值）= IIN_HOST 设定值
- **ILIM2**（过载值）= ILIM1 × (110% ~ 450%)，由 ProchotOption0[15:11] 设定
- 时序：先以 ILIM2 运行 TOVLD 时间（1ms/2ms/10ms/20ms 可配），再以 ILIM1 运行 TMAX−TOVLD 时间
- TMAX 可配：5ms/10ms/20ms/40ms
- 触发条件：
  - 输入电流超调触发（EN_PKPWR_IDPM = 1）
  - 系统电压跌落触发（EN_PKPWR_VSYS = 1）

#### 2.3.4 ICO（输入电流优化器）

自动提取适配器最大可用功率。使能后（EN_ICO_MODE = 1），算法自动搜索适配器不崩溃的最大输入电流，完成后 ICO_DONE 状态位置 1。

### 2.4 USB OTG（反向供电）

从电池向 USB 端口供电（反向 Boost 模式）：

| 参数 | 规格 | 寄存器 |
|------|------|--------|
| 输出电压范围 | 3V ~ 20.8V（高范围 4.28V~20.8V / 低范围 3V~19.52V） | OTGVoltage (0x3B) + OTG_RANGE_LOW (0x32[2]) |
| 输出电压分辨率 | 8mV（12-bit DAC） | 0x3B |
| 输出电流范围 | 0 ~ 6350mA | OTGCurrent (0x3C) |
| 输出电流分辨率 | 50mA（7-bit DAC） | 0x3C |
| 电压转换斜率 | 可配置，符合 USB PD 3.0 PPS 规范 | — |
| 轻载模式 | PWM → PFM 自动切换 | — |
| 兼容标准 | USB PD 5V/9V/15V/20V；USB Type-C 500mA/1.5A/3A/5A | — |

**OTG 使能条件**：
1. 有效电池电压设定（不触发 BATOVP）
2. OTG 输出电压/电流已设定
3. OTG/VAP 引脚 HIGH + REG0x32[12] = 1 + REG0x32[5] = 1
4. VBUS < VVBUS_CONVENZ（约 3.2V）

---

### 2.5 VAP（Vmin Active Protection，最小电压有源保护）

仅在电池供电且无外部 OTG 负载时启用，为 **Intel IMVP9 平台推荐功能**：

**工作原理**：
1. 将电池能量泵送至 VBUS 输入去耦电容，充电至高压（如 20V）储存能量
2. 当 SoC 出现高峰值功率脉冲（如 Intel Turbo）时，电池大电流拉取导致 VSYS 骤降
3. 储存在输入电容中的能量自动补充系统，防止 VSYS 跌落至最小系统电压以下导致黑屏/崩溃

**进入 VAP 步骤**：
1. 设定 VBUS 充电电压 (REG0x3B)
2. 设定 VBUS 充电电流 (REG0x3C, REG0x34[15:10])
3. 设定 VSYS_MIN 调节点 (REG0x3E[13:8])
4. 设定 VAP 触发 VBUS 放电的 VSYS_TH1 阈值 (REG0x33[7:4])
5. 设定 PROCHOT_VSYS_TH2 阈值以触发 SoC 降频 (REG0x33[3:2])
6. 使能 VAP：REG0x32[5] = 0，REG0x32[12] = 0，拉高 OTG/VAP 引脚

**退出 VAP**：主机写 REG0x32[5] = 1 或拉低 OTG/VAP 引脚。任何常规故障条件会自动退出 VAP。

**Conservative VAP 模式**（REG0x32[6] = 1）：更保守的能量释放策略。

---

### 2.6 PTM（Pass Through Mode，直通模式）

TI 专利技术，适用于系统睡眠或轻载工况：

- Buck 和 Boost 高侧 MOSFET（Q1、Q4）同时导通
- Buck 和 Boost 低侧 MOSFET（Q2、Q3）同时关断
- 输入功率直接穿透到系统，省去开关损耗和电感磁芯损耗

**进入 PTM 步骤**：
1. REG0x31[7] = 0（禁用 EN_EXTILIM）
2. REG0x30[8] = 1（PTM_PINSEL，ILIM_HIZ 引脚改为 PTM 控制）
3. REG0x30[2] = 1（EN_PTM）
4. 拉低 ILIM_HIZ 引脚

**退出 PTM**：REG0x30[2] = 0；拉高 ILIM_HIZ 引脚；或触发 VINDPM / 故障条件时自动退出。

---

### 2.7 PROCHOT（处理器过热指示）

符合 IMVP8 / IMVP9 规范，直接向 CPU 发送降频信号（/PROCHOT 引脚，开漏低有效）。

#### 2.7.1 触发事件（共 9 个事件源）

| 事件 | 说明 | 使能位 | 阈值设置 |
|------|------|--------|---------|
| **ICRIT** | 适配器峰值电流 > ILIM2 的 110% | REG0x34[5] | ILIM2_VTH (REG0x33[15:11]) |
| **INOM** | 适配器平均电流 > IIN_HOST 的 110% | REG0x34[4] | 固定 110% |
| **IDCHG** | 电池放电电流超阈值 | REG0x34[3] | IDCHG_VTH (REG0x34[15:10])，范围 0~32256mA，步进 512mA，128mA 偏移 |
| **VSYS** | 系统电压低于阈值 | REG0x34[2] | VSYS_TH2 (REG0x33[3:2])，1s: 3.1/3.3/3.5/3.7V；2s-4s: 5.9/6.2/6.5/6.8V |
| **VDPM** | VBUS 低于 VINDPM 的 80%/90%/100% | REG0x34[7] | REG0x33[8] 决定 80% 或 90% |
| **适配器移除** | CHRG_OK 下降沿 | REG0x34[0] | — |
| **电池移除** | CELL_BATPRESZ 下降沿 | REG0x34[1] | — |
| **CMPOUT** | 独立比较器输出 | REG0x34[6] | — |
| **EXIT_VAP** | 退出 VAP 模式（始终使能） | 始终使能 | — |

#### 2.7.2 去抖时间

| 事件 | 可配去抖时间 |
|------|-------------|
| ICRIT | 15μs / 120μs / 500μs / 1ms（REG0x33[10:9]） |
| INOM | 1ms / 50ms（REG0x33[1]） |
| IDCHG | 2ms / 130μs / 8ms / 16ms（REG0x34[9:8]） |
| CMPOUT | 1μs / 2ms / 5s（REG0x30[5:4]） |
| VSYS | 固定 5μs |
| VDPM | 固定 |

#### 2.7.3 脉宽与脉冲扩展

- **单脉冲模式**（REG0x21[14] = 0）：最小脉宽可配 100μs / 1ms / 10ms / 5ms（REG0x21[13:12]）。脉宽结束后若事件仍存在，脉冲自动延长。
- **脉冲扩展模式**（REG0x21[14] = 1）：PROCHOT 保持低电平直到主机写 REG0x21[11] = 0 清除。
- **PROCHOT_VDPM 和 PROCHOT_EXIT_VAP**：始终需要主机清除，无论脉冲模式。

#### 2.7.4 低功耗 PROCHOT

电池低功耗模式下（REG0x12[15] = 1），可用独立比较器监控系统电压，约 150μA 功耗实现 VSYS 监控：

- REG0x30[14:13] = 01b
- 独立比较器阈值固定 1.2V
- REG0x30[13] = 1 时监控系统电压（CMPIN 接至 VSYS 比例电压）

#### 2.7.5 PROCHOT 状态寄存器

REG0x21[8:0] 报告触发事件，读后若事件不再活跃则自动清零。STAT_VDPM / STAT_EXIT_VAP / STAT_VAP_FAIL 需主机写 0 清除。

### 2.8 电流与功率监测

#### 2.8.1 IADPT（输入电流模拟输出）

| 参数 | 规格 |
|------|------|
| 增益 | 20× 或 40×（REG0x12[4]） |
| 方向 | 正向充电：V(IADPT) = 增益 × (VACP−VACN)；OTG 反向：V(IADPT) = 增益 × (VACN−VACP) |
| 输出钳位电压 | 3.3V（典型） |
| 精度 | ±2%（40.96mV 差模电压时） |
| 最大输出电容 | 100pF |

**电感检测功能**：通过 IADPT 引脚外接电阻自动识别电感值（上电时检测一次）：
- 1μH → 93kΩ
- 2.2μH → 137kΩ
- 3.3μH → 169kΩ
要求电阻精度 ±3% 或更高。

#### 2.8.2 IBAT（电池电流模拟输出）

| 参数 | 规格 |
|------|------|
| 增益 | 8× 或 16×（REG0x12[3]） |
| 方向 | 充电：V(IBAT) = 增益 × (VSRP−VSRN)；放电：V(IBAT) = 增益 × (VSRN−VSRP) |
| 输出钳位电压 | 3.3V（典型） |
| 最大输出电容 | 100pF |
| IBAT 方向选择 | REG0x31[6]：0 = 放电电流输出，1 = 充电电流输出 |

#### 2.8.3 PSYS（系统功率监测）

符合 IMVP8 / IMVP9 规范，电流型输出：

| 参数 | 规格 |
|------|------|
| 增益（PSYS_RATIO） | 1μA/W（默认，REG0x30[9] = 1）或 0.25μA/W（REG0x30[9] = 0） |
| 输出范围 | 0 ~ 160μA |
| 输出钳位电压 | 3.3V |
| 精度 | ±4%（45W，仅适配器）；±3%（44W，仅电池） |
| 使能 | REG0x30[12] = 1（默认关闭以节省功耗） |
| 检测电阻 | RAC/RSR 可选 10mΩ 或 20mΩ（REG0x30[11:10]） |
| OTG 模式下行为 | REG0x32[0]：0 = PSYS = 电池放电功率 − OTG 输出功率；1 = PSYS = 仅电池放电功率 |

计算公式：`V(PSYS) = RPSYS × KPSYS × (VACP × IIN + VBAT × IBAT)`

### 2.9 集成 ADC（数字监测）

8 通道 ADC，支持单次（One-Shot）和连续（每 1 秒）转换模式。

| 通道 | 全量程 | LSB | 寄存器 | 使能位 |
|------|--------|-----|--------|--------|
| VBUS（输入电压） | 3.2V ~ 19.52V | 64mV | REG0x23[15:8] | REG0x35[6] |
| PSYS（系统功率） | 3.06V | 12mV | REG0x23[7:0] | REG0x35[5] |
| ICHG（充电电流） | 8.128A | 64mA | REG0x24[14:8] | REG0x35[2] |
| IDCHG（放电电流） | 32.512A | 256mA | REG0x24[6:0] | REG0x35[3] |
| IIN（输入电流） | 12.75A（10mΩ: 6.4A） | 50mA | REG0x25[15:8] | REG0x35[4] |
| CMPIN（比较器输入电压） | 3.06V | 12mV | REG0x25[7:0] | REG0x35[7] |
| VSYS（系统电压） | 2.88V ~ 19.2V | 64mV | REG0x26[15:8] | REG0x35[1] |
| VBAT（电池电压） | 2.88V ~ 19.2V | 64mV | REG0x26[7:0] | REG0x35[0] |

- **ADC 量程选择**（REG0x35[13]）：输入电压 < 5V 或 1S 电池时推荐 2.04V 量程（=0），否则推荐 3.06V 量程（=1，默认）
- **ADC_START**（REG0x35[14]）：写 1 启动转换，单次完成后自动回 0
- **ADC_CONV**（REG0x35[15]）：0 = 单次；1 = 连续（每秒更新一次）
- **低功耗模式下 ADC 不可用**
- 转换顺序：VBAT → VSYS → ICHG → IDCHG → IIN → PSYS → VBUS → CMPIN
- 典型转换时间：10ms/通道

片内独立模拟比较器：

| 参数 | 选项 0 | 选项 1 |

### 2.11 保护功能汇总

| 保护 | 阈值 | 行为 | 恢复条件 |
|------|------|------|---------|

#### 3.2.2 ChargeCurrent (0x14) — 默认 0x0000

```
BIT:  15:13     12              11              10              9
      Reserved  ChargeCurrent_  ChargeCurrent_  ChargeCurrent_  ChargeCurrent_
                bit6            bit5            bit4            bit3
BIT:  8               7               6               5:0
      ChargeCurrent_  ChargeCurrent_  ChargeCurrent_  Reserved
      bit2            bit1            bit0
```

| 位 | 字段 | 类型 | 默认 | 权重（10mΩ 检流电阻） |
|----|------|------|------|----------------------|
| 15:13 | Reserved | R/W | 000 | 不使用，写 1 无效 |
| 12 | ChargeCurrent, bit6 | R/W | 0 | 4096 mA |
| 11 | ChargeCurrent, bit5 | R/W | 0 | 2048 mA |
| 10 | ChargeCurrent, bit4 | R/W | 0 | 1024 mA |
| 9 | ChargeCurrent, bit3 | R/W | 0 | 512 mA |
| 8 | ChargeCurrent, bit2 | R/W | 0 | 256 mA |
| 7 | ChargeCurrent, bit1 | R/W | 0 | 128 mA |
| 6 | ChargeCurrent, bit0 | R/W | 0 | 64 mA |
| 5:0 | Reserved | R/W | 000000 | 不使用，值忽略 |

**计算公式**（10mΩ 检流电阻）：
- I_CHG(mA) = (ChargeCurrent_Code) × 64，Code 范围 0~127
- 写入值超出范围的上限被钳位到 8128mA

**重要行为**：
- POR 后为 0（不充电）
- CHRG_OK 变低（除 ACOV 外）→ 复位为 0
- CELL_BATPRESZ 变低（电池移除）→ 复位为 0
- ACOC、TSHUT、Power Path Latch-Off、SYSOVP **不**复位 ChargeCurrent
- 需先写 MaxChargeVoltage 再写 ChargeCurrent 才启动充电

## 四、寄存器配置常见问题与陷阱

### 4.1 ChargeCurrent 必须先于 ChargeVoltage 写入？→ 错误，顺序相反！

**正确顺序：先写 MaxChargeVoltage (0x15)，再写 ChargeCurrent (0x14)。**

手册第 57 页明确说明：
> "If the battery is different from 4.2 V/cell, the host has to write to REG0x15() **before** REG0x14() for correct battery voltage setting."

若未写 REG0x15 而先写 REG0x14，充电将以默认充电电压（1S=4.192V/4.200V）启动，可能导致电池过压。

### 4.2 看门狗超时后 ChargeCurrent 清零

看门狗超时（175s 默认）后：
- **ChargeCurrent (0x14) 被强制清零**
- 其他所有寄存器值保持不变
- 充电被暂停，需重新写 ChargeCurrent 或 ChargeVoltage 恢复
- 重写 REG0x12[14:13] = 00（禁用看门狗）也可恢复
- 周期性写 REG0x15 或 REG0x14 即可"喂狗"

### 4.3 电池移除 / 适配器移除导致寄存器重置

| 事件 | 影响 |
|------|------|
| **CELL_BATPRESZ 变低（电池移除）** | ChargeCurrent 清零；ChargeVoltage 回默认值；退出 LEARN 模式；IDPM_AUTO_DISABLE 若使能则 EN_IDPM 清零 |
| **CHRG_OK 变低（适配器移除，除 ACOV 外）** | ChargeCurrent 清零；IIN_HOST 回默认 3.25A；PKPWR 相关位清零 |
| **ACOV 故障** | ChargeCurrent **不**复位 |
| **ACOC/TSHUT/SYSOVP/Power Path Latch-Off** | ChargeCurrent **不**复位 |

**实践提示**：重新插入电池后必须重新写入 ChargeVoltage 和 ChargeCurrent。

### 4.4 EN_LWPWR 与性能的关系

- **EN_LWPWR = 1**（默认）：低功耗模式。仅电池时最低 22μA 静态电流。禁用 PROCHOT、IBAT/PSYS 缓冲、独立比较器。**ADC 不可用**。独立比较器可通过 REG0x30[14] 或 [13] 单独使能。
- **EN_LWPWR = 0**（性能模式）：PROCHOT、电流/功率监测缓冲和比较器按寄存器设置正常工作。REGN LDO 始终开启。电池供电时静态电流约 880~1270μA。

**常见陷阱**：默认上电后处于低功耗模式，ADC 和大部分监测功能不可用。必须先设 EN_LWPWR = 0 才能使用 ADC 和监测功能。

### 4.5 ILIM_HIZ 引脚与 IIN_HOST 寄存器的取小逻辑

- 实际输入电流限制 = **min(ILIM_HIZ 引脚设定, IIN_HOST 寄存器设定)**
- ILIM_HIZ 引脚电压 < 0.4V → 进入 Hi-Z 模式（非输入限流）
- ILIM_HIZ 引脚电压 > 0.8V → 退出 Hi-Z 模式
- ILIM_HIZ 公式：V(ILIM_HIZ) = 1V + 40 × IDPM × RAC
- 可通过 REG0x31[7] = 0 禁用 ILIM_HIZ 引脚（仅用寄存器限流）
- 拉高 ILIM_HIZ > 4.0V 也可禁用引脚功能

**常见陷阱**：若 ILIM_HIZ 引脚分压电阻设计使电压对应的限流值低于寄存器设定值，实际限流将以引脚值为准，可能意外限制充电电流。

### 4.6 寄存器汇总表笔误：MaxChargeVoltage LSB

**Table 9-6（第 34 页）寄存器汇总表标注 MaxChargeVoltage "LSB 16 mV" 是错误的。**
这是从 BQ25700A 数据手册复用旧描述未更新所致（BQ25700A 确实是 16mV）。实际 LSB = 8mV，以下多处确认：

- 第 5 页 设备对比表：Charging Voltage Resolution = 8mV
- 第 57 页 寄存器详细描述："with 8-mV step resolution"
- 第 57-58 页 位域描述：bit3 = 8mV, bit4 = 16mV...

### 4.7 1S/2S/3S/4S 配置下 SYSOVP 阈值差异

SYSOVP 阈值由 CELL_BATPRESZ 引脚偏置决定：

| 节数 | 分压比 | SYSOVP 阈值 | 默认 ChargeVoltage |
|------|--------|-----------|-------------------|
| 1S | 25% REGN | **5V** | 4.192V |
| 2S | 40% REGN | **12V** | 8.400V |
| 3S | 55% REGN | **19.5V** | 12.592V |
| 4S | 75% REGN | **19.5V** | 16.800V |

**1S 特殊情况**：即使 ChargeVoltage 被改写为 3.600V（LiFePO4），SYSOVP 仍保持在 5V，不会随 ChargeVoltage 改变。

### 4.8 ADC 连续模式对功耗的影响

- ADC 连续模式（REG0x35[15] = 1）：芯片每 1 秒执行一次全通道 ADC 转换
- 典型转换时间 10ms/通道 × 8 通道 = 80ms/周期
- ADC 使能期间芯片无法进入最低功耗状态
- **建议**：不需要实时监测时使用单次模式（REG0x35[15] = 0），每次需要数据时写 REG0x35[14] = 1 触发

### 4.9 PROCHOT 脉冲扩展模式下需要主机清除的注意事项

当 REG0x21[14] = 1（脉冲扩展模式）时：
- PROCHOT 引脚一旦触发，将**保持低电平**直到主机写 REG0x21[11] = 0
- 即使触发事件已经消失，PROCHOT 也不会自动释放
- **PROCHOT_VDPM 和 PROCHOT_EXIT_VAP**：无论脉冲模式，始终需要主机清除（REG0x21[7] 和 REG0x21[8] 写 0）
- 如果在脉冲扩展期间发生第二个事件，状态位会累积，但 PROCHOT 保持低

### 4.10 写 ChargeVoltage = 0 的副作用

写 REG0x15 = 0x0000 会导致：
1. ChargeVoltage 恢复为 CELL_BATPRESZ 决定的默认值
2. **ChargeCurrent 被强制清零**（充电被禁用）

这不是读取默认值的正确方式，应使用 RESET_REG (REG0x32[14]) 整体复位。

### 4.11 1S 预充电特殊行为

1S 配置下预充电有独特的两阶段行为（第 56 页）：

| 电池电压 | 预充电电流 | BATFET 模式 |
|---------|-----------|------------|
| VSRN < 3V（BATLOWV 下降阈值 2.8V，上升阈值 3V） | 384mA 钳位 | LDO 模式 |
| 3V < VSRN < 最小系统电压 | **2A 钳位** | LDO 模式 |
| VSRN > 最小系统电压 | 按 ChargeCurrent 设定 | 全导通（CC 模式） |

这意味着 1S 电池在 3V 到最小系统电压（如 3.584V/3.072V）之间时，充电电流被硬件钳位在 2A，即使 ChargeCurrent 设定更高也无效。

### 4.12 系统中无 BATFET 的配置陷阱

如果系统设计不包含 BATFET（VSYS 短接至 SRP），必须在转换器启动前按以下顺序操作（第 59-60 页）：
1. 适配器插入前进入 Hi-Z 模式（拉低 ILIM_HIZ 或 REG0x32[15] = 1）
2. 设 REG0x12[2] = 0 禁用 LDO 模式
3. 设 REG0x30[0] = 0 禁用自动唤醒
4. 检查电池电压设定
5. 设定预充电/充电电流
6. 退出 Hi-Z 模式时先用低输入电流限制（几百 mA）防止浪涌

### 5.2 硬件先决条件

1. CELL_BATPRESZ 引脚分压为 25% REGN（如 Rtop=30kΩ, Rbottom=10kΩ → V = 6V × 10/(30+10) = 1.5V）
2. 检流电阻 RAC = RSR = 10mΩ（典型）
3. 电感 2.2μH，IADPT 对地电阻 137kΩ ±3%
4. BATFET（P 沟道 MOSFET，Ciss 1nF~3nF）正确接入
5. SDA/SCL 各 10kΩ 上拉

### 5.3 上电初始化序列（含延时要求）

```
步骤 0:  等待 VBUS 上电
         └─ 条件: VBUS > 3.5V（VVBUS_CONVEN 典型值）
         └─ CHRG_OK 在 50ms 后变高
         └─ 等待 CHRG_OK 变高（确认无故障）

步骤 1:  延时 ≥ 150ms
         └─ 从 VBUS > VVBUS_CONVEN 起计时
         └─ 此期间：LDO 启动 → CELL 配置 → 默认 VINDPM/IDPM 设定
         └─ 150ms 后转换器上电

步骤 2:  读取 ChargeOption3 (0x32) 确认器件就绪
         └─ 期望读回 0x0030（默认值）
         └─ 若 EN_HIZ=1，写 0 退出 Hi-Z

步骤 3:  写入 MaxChargeVoltage (0x15) = 0x0A10
         └─ 3.600V = 1024 + 322×8 = 3600mV ✓
         └─ 必须先于 ChargeCurrent！

步骤 4:  写入 ChargeOption0 (0x12) = 0x660E
         └─ EN_LWPWR=0（性能模式）
         └─ WDTMR_ADJ=10（看门狗 88s）
         └─ EN_OOA=1（避免音频噪声）
         └─ PWM_FREQ=1（800kHz，配合 2.2μH 电感）
         └─ IADPT_GAIN=0（20×）、IBAT_GAIN=1（16×）
         └─ EN_LDO=1（使能预充电 LDO）
         └─ EN_IDPM=1（使能输入电流调节）

步骤 5:  写入 MinSystemVoltage (0x3E) = 0x0800
         └─ 3.072V = 1024 + 8×256 = 3072mV ✓
         └─ 低于标称 3.2V，保证正常放电深度

步骤 6:  写入 IIN_HOST (0x3F) = 0x3B00
         └─ 3000mA = 50 + 59×50 ✓（适配器 3A）

步骤 7:  【关键】写入 ChargeCurrent (0x14) = 0x0400
         └─ 1024mA = 16×64 ✓
         └─ 此写入启动充电
         └─ 充电使能后，充电电流以 64mA/8μs 步进软启动

步骤 8:  喂狗循环（周期性，间隔 < 88s）
         └─ 写 ChargeCurrent (0x14) = 0x0400（重写相同值即可）
         └─ 或写 MaxChargeVoltage (0x15) = 0x0A10
         └─ 看门狗在每次写 REG0x15 或 REG0x14 时自动重置
```

### 5.4 可选配置

### 5.5 SMBus 通信示例（Write-Word 协议）

